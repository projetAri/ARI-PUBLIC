
# PROJET ARI

**Independent Research & Development / Recherche et développement indépendant**

*Associative Artificial Intelligence · Governed Learning · Human–AI Co-engineering*

**ARI — An Experience-Centric Architecture for Associative and Continual Artificial Intelligence**

ARI is an independent experimental research project investigating how artificial intelligence systems can organize experiences, construct associations between memories, manage contradictory evidence, and revise knowledge through governed, traceable processes.

The project explores collaboration between human researchers and AI-assisted engineering while maintaining human oversight, reproducibility, and explicit limits on system autonomy.

**Scientific status:** Exploratory research conducted independently. Internal experimental milestones do not constitute external scientific validation.

### What is ARI?

ARI is an experimental architecture centered on a simple idea:

> An intelligent system should not only accumulate information. It should build, test, trace, revise, and reuse relationships between information through experience.

ARI treats **experience** as a first-class object and organizes learning around traceable evidence, authority, conflicts, hypotheses, validation, and revision.

### Research direction

ARI explores an experience-centric loop:

**Event → Experience → Memory → Associations → Hypothesis → Test → Evidence → Validation → Knowledge → Action → New Event**

The intended long-term property is a memory whose **relationships can evolve under governance**, rather than a static store of retrieved documents.
